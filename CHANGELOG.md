# Changelog

## 1.0.0 - 2026-07-26

- Standalone ESP32 OBD-II/CAN firmware with simulator and read-only vehicle mode.
- LILYGO T-A7670 MicroPython Wi-Fi AP, TCP ingestion and 4G MQTT gateway.

- AWS IoT Core to DynamoDB storage path.
- AWS SAM Lambda/API and responsive Vehicle Health dashboard.
- Standard Mode 01 PID, Mode 03 DTC, trip/fuel estimation and maintenance model.
